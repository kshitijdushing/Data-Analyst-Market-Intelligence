# Data

This folder contains information about the dataset used for the **Data Analyst Market Intelligence** project.

## Data Source

The original dataset was sourced from Kaggle:

**Indian Job Market Dataset 2025**

Dataset by **Shivam Shrivastava**

[View dataset on Kaggle](https://www.kaggle.com/datasets/shivamshrivastava21/indian-job-market-dataset-2025-2026)

## Dataset Description

The source dataset contains Indian job-market information, including fields related to:

- Job titles
- Job IDs
- Companies
- Locations
- Experience requirements
- Skills
- Salary information
- Company-related information

For this project, the dataset was filtered and prepared for analysis of **Data Analyst job postings**.

## Data Preparation

The data was prepared as part of the project workflow using Python and SQL.

The preparation included:

- Cleaning and standardizing relevant fields
- Processing salary information
- Preparing salary values for numerical analysis
- Extracting individual skills from the original skills field
- Creating a normalized `job_skills` table for skill analysis

The cleaned data was then analyzed using MySQL and connected to Power BI for dashboard development.
